# 智数科技 2027 届校园招聘视频

本仓库整理河南平煤神马智数科技有限公司校招视频的创意方案、逐镜脚本、旁白及已生成的 11 页校招资料图片，并保留招聘原始 PDF 及三部参考片的分析。

当前为创意评审与制作准备版本，主题为 **《让 AI 看懂真实世界》**，副题为“2027 届，来做那个定标准的人”。主版时长 **120 秒、20 个叙事分镜单元、16:9**，构图预留竖版裁切空间。当前尚未制作最终视频。

## 核心创意

用同一份能源设备“边界样本”贯穿全片：现场图像进入标注屏幕，经过规则讨论、复核、三维加工与算法协作，最后成为下一位同事能够使用的案例规范。一条青色标注线连接这些环节，让候选人看清工作任务、协作方式和岗位选择。

| 片段 | 时间 | 任务 |
|---|---|---|
| 提问与公司登场 | 00:00–00:15 | 从真实问题进入，前 15 秒交代企业归属 |
| 工作内容 | 00:15–01:03 | 展示数据加工、质量验证、三维与算法研究 |
| 带教与积累 | 01:03–01:21 | 用具体动作和交付物表达培养方式 |
| 招聘岗位 | 01:21–01:48 | 呈现 2027 届计划招聘 58 人及四类岗位 |
| 回扣与投递入口 | 01:48–02:00 | 回到规范复用，完整落版保持 7 秒 |

## 资料边界

- 业务方向“AI 应用开发”由用户说明；岗位计划与培养机制依据用户提供的招聘 PDF，未作外部事实核验。
- 58 人是招聘计划，其中本科 50 人、硕士 5 人、博士 3 人，不代表现有员工规模。
- 分镜是拟拍／拟制设计，不能视为现有项目、系统或设备已经落地的证明。
- 原材料中的发展目标不按已建成能力表述；“全国唯一”“国字号试点”等主张暂未进入旁白。
- 正式投递二维码或邮箱、薪酬福利、正式 Logo 和可公开项目素材仍待补齐，详见制作准备文档。

本次整理仅包括方案与评审资料，不包括三个参考 MP4 原片、全量抽帧、音频、失败的语音识别结果或依赖缓存。所有文档使用仓库内相对链接，不保留用户微信附件的本地目录。
